# TryHackMe: Windows Fundamentals 1

## Overview

This room introduced core Windows operating system concepts including the desktop's Graphical User Interface (GUI), file systems, user/admin accounts & permissions, and administrative tools. 

## Objectives
- Become familiar with Windows OS components
- Gain understanding of Windows Navigation
- Identify Windows OS security concepts
- Learn common administrative tools

## Skills Practiced
- Windows operating system navigation
- New Technology File System (NTFS) concepts
- User/Administrative account tools and privileges
- Remote Desktop Protocol 
- Windows Settings/Control Panel
